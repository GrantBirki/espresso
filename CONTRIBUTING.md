# Contributing

Thanks for helping improve Espresso.

## Local Setup

```bash
script/bootstrap
```

## Development Commands

```bash
script/update
script/build
script/test
script/lint
script/package
```

Use `script/server` for a local build and launch.

## Pull Requests

- Keep changes focused.
- Add or update tests for behavior changes.
- Update docs when user-visible behavior changes.
- Do not commit generated build output, release artifacts, or local Xcode user state.
